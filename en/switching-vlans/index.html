Switching and VLANs

How to split one set of switches into several separate networks, what access and trunk ports are, and the security settings every switch should have — with Cisco commands.

After this lesson you can
  • Explain what a VLAN is and why it is used
  • Tell an access port from a trunk port and configure both
  • Describe how VLANs reach each other and list the basic security settings of a switch

The problem VLANs solve

A hotel wants guests, staff computers and cameras on separate networks, so that a guest can never reach the accounting server. The obvious way would be three sets of switches and three sets of cables — three times the cost. A VLAN (virtual LAN) does the same with one set: you tell the switch 'ports 1 to 12 are network 10, ports 13 to 20 are network 20', and it treats them as if they were different switches. A device in VLAN 10 cannot even see a device in VLAN 20; traffic between them must go through a router or firewall, where you decide what is allowed.

  • Security: groups that should not reach each other are separated.
  • Less noise: broadcasts stay inside their own VLAN.
  • Flexibility: moving a person to another department is a setting, not a new cable.
  • Each VLAN is its own IP network, with its own subnet and gateway — VLAN 10 might be 192.168.10.0/24 and VLAN 20 192.168.20.0/24.

Access ports and trunk ports

A switch port is one of two kinds. An access port belongs to exactly one VLAN and is where an ordinary device plugs in — a PC, a printer, a camera. The device knows nothing about VLANs. A trunk port carries many VLANs at once and connects switches to each other, or a switch to a router. To keep the VLANs apart on that shared cable, the switch adds a small label to every frame saying which VLAN it belongs to. The standard for that label is called 802.1Q, and the label is called a tag.

Configuring it on a Cisco switch

Cisco's command line has levels. You start in user mode (the prompt ends with >). enable takes you to privileged mode (#), where you can look at everything. configure terminal takes you to configuration mode, where you change things. Commands can be shortened as long as they stay unique, and a question mark shows what you may type next.

Letting VLANs talk: inter-VLAN routing

Separate VLANs are separate networks, so only a router can pass traffic between them. There are two common designs. In 'router on a stick', one trunk cable runs to a router that has a virtual interface for each VLAN. In a layer 3 switch, the switch itself has an address in each VLAN and routes between them, which is faster and is what most offices use today. Either way, that address becomes the default gateway of the devices in that VLAN — and the place where you put rules such as 'guests may reach the internet but not the staff network'.

Loops and the spanning tree

Networks often have spare cables between switches so that one broken link does not cut off a floor. But two paths between the same switches form a loop, and a broadcast frame would circle it forever, multiplying until the network stops within seconds — a broadcast storm. The Spanning Tree Protocol (STP) prevents this automatically: the switches talk to each other, find the loops and block the spare links, opening them again only if the main link fails. It is on by default. Leave it on.

Common mistakes

  • Forgetting to save: copy running-config startup-config.
  • A VLAN that exists on one switch but is not allowed on the trunk between them.
  • Leaving users in VLAN 1, the default that every port starts in.
  • Turning spanning tree off 'to speed things up'.
  • Putting two VLANs in the same IP subnet.

Exercises

Try each one yourself first, then open the answer.

  1. A PC in VLAN 10 cannot ping a PC in VLAN 20 on the same switch. Is that a fault?

    Show the answer
    No — it is the purpose of VLANs. They can only talk through a router or a layer 3 switch.

  2. Write the commands that put port Gi1/0/5 in VLAN 30 as an access port.

    Show the answer
    interface GigabitEthernet1/0/5
 switchport mode access
 switchport access vlan 30

  3. Which kind of port connects two switches, and what does it add to each frame?

    Show the answer
    A trunk port. It adds an 802.1Q tag with the VLAN number.

  4. Someone plugs a home router into a wall socket and people start getting wrong addresses. Which switch feature prevents this?

    Show the answer
    DHCP snooping: only ports marked as trusted may send DHCP offers.

Practise this in the lab

Remember
  • A VLAN is a separate network on shared switches.
  • Access port: one VLAN, for devices. Trunk port: many VLANs, tagged, between switches.
  • VLANs meet only at a router or layer 3 switch.
  • Keep spanning tree on, shut unused ports, save the configuration.
