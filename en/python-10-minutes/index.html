Python: your first real programs

Variables, text, decisions and loops — the core of Python, with tiny examples you can run as you read.

After this lesson you can
  • Store values in variables and print them
  • Make decisions with if, elif and else
  • Repeat work with a for loop over a list

Python is a great first language: it reads almost like English and runs everywhere. If you have Linux or a Mac it's already installed; type python3 in a terminal. This is enough to be genuinely useful.

Values and variables

A variable is a name for a value. You don't declare a type — Python figures it out. print() shows something on the screen.

Making decisions

if / elif / else run different code depending on a condition. Indentation (the spaces at the start of a line) is how Python knows which lines belong together — it isn't decoration.

Repeating with loops

A for loop repeats once for each item in a list. A list holds many values in order, written in square brackets.

Setting up and running a program

Python is already installed on Linux and macOS; on Windows download it from python.org and tick 'Add Python to PATH' during the installation. There are two ways to use it. Typing python3 alone opens an interactive prompt (>>>) where each line runs at once — good for experiments. For real work you write the lines into a file that ends in .py and run the file.

Numbers and text in depth

  • / always gives a decimal result; // drops the fraction; % gives the remainder; ** is 'to the power of'.
  • An f-string — a string with f in front — puts values straight into text: f"{name} is {age}". The :, adds thousands separators.
  • Strings have built-in tools: .upper(), .lower(), .strip() (remove spaces at the ends), .replace(a, b), .split() and .startswith().
  • in asks 'is this inside that?' and answers True or False.

Lists and dictionaries

A list keeps values in order and you reach them by position, counting from zero. A dictionary keeps values under names (keys), like a form with labelled fields. Together they can describe almost anything: a network is a list of devices, and each device is a dictionary.

while loops and functions with defaults

for repeats once for each item. while repeats as long as a condition stays true, so something inside the loop must eventually make it false — otherwise it never ends. A function can give its parameters default values, which are used when the caller leaves them out.

  • break leaves a loop early; continue jumps to the next round.
  • return hands a value back to the caller. A function without return gives back None.
  • Variables created inside a function exist only inside it.
  • Give functions verb names that say what they do: count_failed, is_open, send_report.

When things go wrong: errors

An error is not a failure; it is Python telling you exactly where it stopped. Read the last line first — it names the kind of error. If a problem is expected, such as a file that may not exist, catch it with try and except so the program can answer politely instead of crashing.

ErrorWhat it means
SyntaxErrorThe line is not valid Python: a missing colon, bracket or quote.
IndentationErrorThe spaces at the start of a line are wrong.
NameErrorYou used a name that was never defined — often a typing mistake.
TypeErrorTwo kinds of value were mixed, such as text + number.
IndexError / KeyErrorYou asked a list for a position, or a dictionary for a key, that is not there.
FileNotFoundErrorThe path is wrong, or you are in a different folder than you think.

Files and ready-made modules

with open(...) opens a file and closes it for you when the block ends. Mode "r" reads, "w" replaces the file and "a" adds to its end. Python also ships with hundreds of modules; you bring one in with import. Useful ones early on: math, random, datetime, os, json, csv and ipaddress.

How to keep improving

  • Type every example yourself; change one thing and predict the result before you run it.
  • Solve a small problem of your own each week: rename files, read a CSV, check a list of addresses.
  • When you are stuck, print the value you are unsure about — most bugs are a wrong guess about what a variable holds.
  • Read other people's code: the six tools on this site are short and explained line by line.

Kinds of value, and your first function

Every value has a type. Text is a string (str) and goes in quotes; whole numbers are int; numbers with a decimal point are float; True and False are bool. Python will not mix them silently: "5" + 5 is an error, because one is text and the other a number. Convert with int("5") or str(5).

  • Indentation is part of the language: the lines inside if, for and def start with four spaces.
  • = stores a value; == compares two values.
  • len(x) counts the items of a list or the letters of a string.
  • range(1, 6) gives 1, 2, 3, 4, 5 — the end is not included.
  • Read errors from the bottom up: the last line names the problem, the line above shows where.

Where to go next

With variables, conditions and loops you can already automate small jobs. Next, look at functions (def) to reuse code, and dictionaries to store named data. Our tools section has real Python programs you can read line by line.

Common mistakes

  • Forgetting the colon at the end of if, for or def.
  • Mixing tabs and spaces, or indenting unevenly.
  • Using = where you meant == inside an if.

  3. Write a function double(n) that returns n times 2, and print double(21).

    return n * 2

print(double(21))

  4. Why does print("Age: " + 23) fail, and how do you fix it?

    Show the answer
    Text and a number can't be joined with +. Use print("Age:", 23) or print("Age: " + str(23)).

Practise this in the lab

Remember
  • Variables hold values; every value has a type.
  • if decides, for repeats, def names a piece of work.
  • Indentation and the colon are not optional.
