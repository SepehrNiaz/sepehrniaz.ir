Python in ten minutes

Variables, text, decisions and loops — the core of Python, with tiny examples you can run as you read.

After this lesson you can
  • Store values in variables and print them
  • Make decisions with if, elif and else
  • Repeat work with a for loop over a list

Python is a great first language: it reads almost like English and runs everywhere. If you have Linux or a Mac it's already installed; type python3 in a terminal. This is enough to be genuinely useful.

Values and variables

A variable is a name for a value. You don't declare a type — Python figures it out. print() shows something on the screen.

Making decisions

if / elif / else run different code depending on a condition. Indentation (the spaces at the start of a line) is how Python knows which lines belong together — it isn't decoration.

Repeating with loops

A for loop repeats once for each item in a list. A list holds many values in order, written in square brackets.

Where to go next

With variables, conditions and loops you can already automate small jobs. Next, look at functions (def) to reuse code, and dictionaries to store named data. Our tools section has real Python programs you can read line by line.

Kinds of value, and your first function

Every value has a type. Text is a string (str) and goes in quotes; whole numbers are int; numbers with a decimal point are float; True and False are bool. Python will not mix them silently: "5" + 5 is an error, because one is text and the other a number. Convert with int("5") or str(5).

  • Indentation is part of the language: the lines inside if, for and def start with four spaces.
  • = stores a value; == compares two values.
  • len(x) counts the items of a list or the letters of a string.
  • range(1, 6) gives 1, 2, 3, 4, 5 — the end is not included.
  • Read errors from the bottom up: the last line names the problem, the line above shows where.

Common mistakes

  • Forgetting the colon at the end of if, for or def.
  • Mixing tabs and spaces, or indenting unevenly.
  • Using = where you meant == inside an if.

Exercises

Try each one yourself first, then open the answer.

  1. Print the numbers 1 to 5, one per line.

    Show the answer
    for i in range(1, 6):
    print(i)

  2. Given devices = ["router", "switch", "camera"] , print how many there are.

    Show the answer
    print(len(devices))

  3. Write a function double(n) that returns n times 2, and print double(21).

    Show the answer
    def double(n):
    return n * 2

print(double(21))

  4. Why does print("Age: " + 23) fail, and how do you fix it?

    Show the answer
    Text and a number can't be joined with +. Use print("Age:", 23) or print("Age: " + str(23)).

Practise this in the lab

Remember
  • Variables hold values; every value has a type.
  • if decides, for repeats, def names a piece of work.
  • Indentation and the colon are not optional.
