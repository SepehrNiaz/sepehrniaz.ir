Automate with Bash scripts

Turn a sequence of commands you type every day into one script you run with a single word.

After this lesson you can
  • Write a script, make it runnable and run it
  • Use variables, command output and if in a script
  • Repeat a task for many items with a loop

A Bash script is just a text file full of the same commands you'd type by hand, run top to bottom. If you do something more than twice, it's worth scripting. Create a file ending in .sh and start it with a special first line.

Your first script

The first line, called the shebang, tells the system which program should run the file. Then you add commands and comments (lines starting with #).

Run it

Make the file executable once with chmod, then run it. $(…) runs a command and drops its output into your line — here, today's date.

Variables and conditions

Always put variables in double quotes ("$host", not $host). It saves you from strange bugs when a value contains a space.

Loops, arguments and exit codes

Every command finishes with an exit code: 0 means success, anything else means failure. That is what if really tests. Scripts also receive the words typed after their name: $1 is the first, $2 the second, and $# is how many there were.

  • No spaces around = when you set a variable: name="lab", not name = "lab".
  • $(command) puts a command's output into a variable.
  • Start serious scripts with set -e so they stop at the first error.
  • bash -x script.sh prints every line as it runs — the easiest way to find a bug.
  • To run a script every night, add a line with crontab -e .

Common mistakes

  • Spaces around the = sign.
  • Leaving out the spaces inside [ ] — it must be [ "$a" = "$b" ].
  • Forgetting the quotes around variables, which breaks on names with spaces.

Exercises

Try each one yourself first, then open the answer.

  1. What must the first line of a Bash script be?

    Show the answer
    #!/bin/bash

  2. Store today's date (YYYY-MM-DD) in a variable called today.

    Show the answer
    today=$(date +%Y-%m-%d)

  3. Write a loop that prints the name of every .log file in this folder.

    Show the answer
    for f in *.log; do
  echo "$f"
done

  4. Your script says 'Permission denied' when you run ./backup.sh. Why?

    Show the answer
    It is not executable yet: chmod +x backup.sh

Practise this in the lab

Remember
  • A script is the commands you already know, saved in a file.
  • Exit code 0 means success; if tests exactly that.
  • Quote your variables, and test with bash -x.
