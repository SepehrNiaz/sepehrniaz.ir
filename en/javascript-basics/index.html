JavaScript basics for the web

The language that runs in every browser — including this site. Variables, functions, and making a page react.

After this lesson you can
  • Declare values with const and let
  • Write and call a function
  • Make a page element react to a click

JavaScript is the only programming language that runs natively in web browsers, which makes it the language of interactive websites. Everything that moves on this very page is JavaScript. You can try it right now: open your browser's developer tools (F12) and type into the Console.

Variables and text

Use let for a value that can change and const for one that can't. Text (a “string”) goes in quotes, and backticks let you drop values straight into text with ${…}.

Functions

A function is a named block of code that takes inputs and gives back a result. It lets you write something once and use it many times.

Making the page react

JavaScript's real job in a browser is to respond to the user. You find an element on the page and tell it what to do when something happens — here, when a button is clicked.

Everything on this website — the page turning in the book, the chat assistant, the language switch — is plain JavaScript, no framework. View the source to see it.

Where JavaScript runs

JavaScript is the only programming language every web browser understands, so it runs on the visitor's own device, not on the server. A page is made of three layers: HTML is the content, CSS is the look, and JavaScript is the behaviour. You attach a script to a page with a script tag, and you see its messages and errors in the browser console.

Types, and the traps between them

  • Everything typed into a form arrives as text. Convert it with Number(value) before you calculate.
  • === compares the value and the type. == converts first, which is how 5 == "5" becomes true. Use === always.
  • undefined means 'no value was given'; null means 'deliberately empty'.
  • Template strings use backticks and ${ }: `Hello ${name}` .

Decisions and loops

Arrays: the tools you will use every day

The short form (p) => p + 1 is an arrow function: it takes p and gives back p + 1. It is the same as writing function (p) { return p + 1; }. Other everyday tools: push adds to the end, pop removes the last item, length counts, sort orders, and forEach runs something for each item.

Objects and JSON

JSON.stringify turns an object into text and JSON.parse turns the text back into an object. With these two you can save data in the browser: localStorage.setItem("device", JSON.stringify(device)) keeps it even after the page is closed, and JSON.parse(localStorage.getItem("device")) brings it back.

Changing the page: the DOM

When the browser reads HTML it builds a tree of objects called the DOM. JavaScript can find any element in that tree and change it; the page updates at once.

Use textContent for anything a visitor typed. innerHTML treats text as HTML, so a visitor could type a script into your page — the attack called XSS.

Finding your own bugs

  • Open the console (F12) first. A red line names the file and line number of the problem.
  • console.log the value you are unsure about, just before the line that fails.
  • 'Cannot read properties of null' means querySelector found nothing: check the id and where the script tag is.
  • 'x is not defined' is nearly always a spelling mistake or a variable used outside the block it was made in.
  • Change one thing at a time, and reload.

Arrays, objects and the page

Two containers do most of the work in JavaScript. An array is an ordered list: [22, 80, 443]. An object groups named values: { name: "router", ip: "192.168.1.1" }. Real programs are mostly arrays of objects, and loops that walk through them.

  • Use const by default; use let only when the value must change.
  • === compares strictly. Avoid ==, which quietly converts types.
  • Press F12 in your own pages to open the console — errors appear there in red.
  • document.querySelector finds an element; .textContent changes its text.
  • A script must run after the element exists: put the script tag at the end of the page.

Common mistakes

  • Changing a const and getting 'Assignment to constant variable'.
  • querySelector returns null because the id is misspelt or the script ran too early.
  • Forgetting return — the function then gives back undefined.

Try each one yourself first, then open the answer.

  return n * n;
}
console.log(square(7));

  2. Log how many items are in const ports = [22, 80, 443];

    Show the answer
    console.log(ports.length);

  3. Log every number from 1 to 5 with a for loop.

    Show the answer
    for (let i = 1; i <= 5; i++) {
  console.log(i);
}

  4. What is wrong here? const count = 0; count = count + 1;

    Show the answer
    A const can't be reassigned. Declare it with let.

Remember
  • const and let hold values; functions name a piece of work.
  • Arrays are lists, objects are named values.
  • The page reacts through events such as click.
