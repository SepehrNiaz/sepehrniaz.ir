SQL از صفر: سؤال‌پرسیدن از داده

پایگاه‌داده و جدول چیست و چطور با SQL داده را بخوانی، فیلتر کنی، مرتب کنی، بشماری، تغییر بدهی و به هم وصل کنی — هر دستور کلمه‌به‌کلمه، با خروجی واقعی.

بعد از این درس می‌توانی
  • توضیح بدهی جدول، ردیف، ستون و کلید اصلی چیست
  • با SELECT، WHERE، ORDER BY و LIMIT داده بخوانی
  • با COUNT، AVG و GROUP BY خلاصه بسازی و با JOIN دو جدول را وصل کنی
  • با INSERT، UPDATE و DELETE داده را ایمن تغییر بدهی

پایگاه‌داده چیست؟

پایگاه‌داده جایی منظم برای نگه‌داشتن اطلاعات است تا بشود سریع دوباره پیدایش کرد. یک صفحه‌ی اکسل را تصور کن: جدول ستون دارد (نام، شهر، نمره) و ردیف (برای هر دانش‌آموز یک ردیف). پایگاه‌داده مجموعه‌ای از همین جدول‌هاست که برنامه‌ای نگهش می‌دارد؛ برنامه‌ای که میلیون‌ها ردیف را در یک لحظه جست‌وجو می‌کند و اجازه می‌دهد چند نفر هم‌زمان استفاده کنند. تقریباً هر برنامه‌ای که استفاده می‌کنی — فروشگاه، بانک، پیام‌رسان — اطلاعاتش را همین‌طور نگه می‌دارد.

SQL (بخوان «سی‌کوئل» یا «اس‌کیو‌ال») زبانِ حرف‌زدن با آن برنامه است. مثل پایتون یک زبان برنامه‌نویسی همه‌کاره نیست: یک کار می‌کند — توصیف داده‌ای که می‌خواهی — و تقریباً مثل انگلیسی خوانده می‌شود. همین SQL با تفاوت‌های کوچک در SQLite، MySQL، PostgreSQL و Microsoft SQL Server کار می‌کند. این درس از SQLite استفاده می‌کند؛ همان چیزی که زبانه‌ی SQL آزمایشگاه تمرین اجرا می‌کند.

  • کلمه‌های SQL مثل SELECT را می‌شود با حروف بزرگ یا کوچک نوشت. حروف بزرگ فقط عادتی است که آن‌ها را مشخص‌تر می‌کند.
  • هر دستور با نقطه‌ویرگول ; تمام می‌شود.
  • مقدار متنی داخل نقل‌قول تکی می‌آید: 'Shiraz'. عدد نقل‌قول ندارد.
  • فاصله و شکستن خط مهم نیست؛ دستورهای بلند را برای خوانایی در چند خط بنویس.

ساختن جدول: CREATE TABLE

تکه‌تکه بخوانش. CREATE TABLE students یک جدول جدید و خالی به اسم students می‌سازد. داخل پرانتز برای هر ستون یک خط هست: اسم ستون و بعد نوع مقداری که نگه می‌دارد. INTEGER عدد صحیح است و TEXT متن. PRIMARY KEY ستونی را مشخص می‌کند که هر ردیف را یکتا می‌شناسد — پایگاه‌داده خودش ۱، ۲، ۳ را پر می‌کند. NOT NULL یعنی «این ستون نباید خالی بماند».

اضافه‌کردن ردیف: INSERT

خواندن: SELECT

SELECT دستوری است که نود درصد وقت‌ها استفاده می‌کنی. شکلش این است: SELECT کدام ستون‌ها FROM کدام جدول. ستاره یعنی «همه‌ی ستون‌ها».

فیلترکردن: WHERE

WHERE فقط ردیف‌هایی را نگه می‌دارد که شرط برایشان درست باشد. دقت کن که SQL برای مقایسه یک = تکی دارد — برخلاف == در پایتون.

شرطمعنی
grade = 20دقیقاً ۲۰
grade <> 20غیر از ۲۰ (به شکل != هم نوشته می‌شود)
grade BETWEEN 10 AND 15از ۱۰ تا ۱۵، هر دو شامل
city IN ('Shiraz', 'Tehran')هر مقداری از فهرست
name LIKE '%a'با a تمام می‌شود
city IS NULLستون خالی است (هیچ‌وقت = NULL ننویس)
NOT, AND, ORترکیب شرط‌ها؛ وقتی AND و OR را با هم می‌آوری پرانتز بگذار

مرتب‌کردن و محدودکردن: ORDER BY و LIMIT

جدول از خودش ترتیب ثابتی ندارد. اگر ترتیب مهم است همیشه ORDER BY بنویس.

شمردن و میانگین‌گرفتن

برای هر گروه یک جواب: GROUP BY

GROUP BY city ردیف‌ها را دسته‌دسته می‌کند، برای هر شهر یک دسته، و بعد تابع‌های شمارش برای هر دسته یک جواب می‌دهند. همین یک ایده بیشتر گزارش‌های دنیا را می‌سازد: فروش در هر ماه، تیکت در هر بخش، ورود ناموفق از هر آدرس.

تغییر و حذف: UPDATE و DELETE

UPDATE و DELETE بدون WHERE روی همه‌ی ردیف‌های جدول اثر می‌گذارند و برگشتی ندارد. اول WHERE را بنویس؛ بهتر از آن، همان شرط را اول با SELECT اجرا کن تا ببینی کدام ردیف‌ها تغییر می‌کنند.

وصل‌کردن جدول‌ها: JOIN

پایگاه‌داده‌های واقعی اطلاعات را بین چند جدول تقسیم می‌کنند تا هیچ‌چیز دو بار نوشته نشود. اینجا جدول دومی به اسم courses با نگه‌داشتن id دانش‌آموز — نه اسمش — ثبت می‌کند هر دانش‌آموز چه درسی دارد. JOIN دو جدول را هر جا id‌ها یکی باشند کنار هم می‌گذارد.

بخش ON قانونِ جورکردن است: «هر درس مال دانش‌آموزی است که id او برابر student_id آن درس باشد». نوشتن table.column (مثل students.name) می‌گوید ستون از کدام جدول است و وقتی هر دو جدول ستونی هم‌نام مثل id دارند لازم است.

ترتیبی که SQL با آن فکر می‌کند

تو اول SELECT را می‌نویسی ولی پایگاه‌داده از آنجا شروع نمی‌کند. دانستن ترتیب واقعی بیشتر خطاهای گیج‌کننده را توضیح می‌دهد — مثلاً اینکه چرا نمی‌شود اسمی را که با AS ساخته‌ای داخل WHERE استفاده کرد.

قدمبخشچه می‌شود
1FROM / JOINانتخاب و وصل‌کردن جدول‌ها
2WHEREدورریختن ردیف‌هایی که جور نیستند
3GROUP BYدسته‌بندی ردیف‌های باقی‌مانده
4HAVINGدورریختن گروه‌هایی که جور نیستند
5SELECTانتخاب ستون‌ها و محاسبه
6ORDER BYمرتب‌کردن نتیجه
7LIMITنگه‌داشتن ردیف‌های اول

خواندن خطاهای SQL

برای حرفه‌ای‌ها: داده‌ی امن و سریع

  • هیچ‌وقت SQL را با چسباندن متنی که کاربر تایپ کرده نساز. «تزریق SQL» — یکی از رایج‌ترین حمله‌ها به وب‌سایت‌ها — همین‌طور کار می‌کند. به‌جایش از جای‌نگه‌دار استفاده کن: در پایتون، db.execute("SELECT * FROM students WHERE name = ?", (name,)) .
  • ایندکس مثل نمایه‌ی آخر کتاب است: CREATE INDEX idx_city ON students(city); جست‌وجو روی آن ستون را سریع می‌کند، به قیمت کمی کندترشدن INSERT.
  • تراکنش چند تغییر را یکی می‌کند تا یا همه انجام شوند یا هیچ‌کدام: BEGIN; … COMMIT; (یا ROLLBACK; برای لغو). بانک‌ها به آن وابسته‌اند.
  • کلید خارجی به پایگاه‌داده می‌گوید courses.student_id باید به یک دانش‌آموز واقعی اشاره کند، پس ردیف بی‌صاحب را قبول نمی‌کند.
  • قبل از هر تغییر پرخطر از پایگاه‌داده پشتیبان بگیر. در SQLite کل پایگاه‌داده یک فایل است که می‌شود کپی‌اش کرد.

«سامانه‌ی ثبت درخواست‌های IT» در بخش ابزارها دقیقاً روی همین دستورها ساخته شده: INSERT برای ثبت تیکت، UPDATE برای بستنش و GROUP BY برای گزارش ماهانه. بعد از این درس آموزش ساختش را باز کن؛ همه‌ی کوئری‌هایش را می‌توانی بخوانی.

اشتباه‌های رایج

  • جاانداختن نقطه‌ویرگول، که باعث می‌شود پایگاه‌داده منتظر ادامه بماند.
  • نقل‌قول دوتایی یا بدون نقل‌قول دور متن: بنویس 'Shiraz'.
  • DELETE یا UPDATE بدون WHERE.
  • نوشتن = NULL به‌جای IS NULL.
  • انتخاب ستونی که نه در GROUP BY آمده و نه داخل تابعی مثل COUNT است.

تمرین

اول خودت امتحان کن، بعد جواب را باز کن.

  1. نام و شهر همه‌ی دانش‌آموزها را به ترتیب نام نشان بده.

    نمایش جواب
    SELECT name, city FROM students ORDER BY name;

  2. دانش‌آموزهای تهران یا اصفهان را که نمره‌شان دست‌کم ۱۵ است نشان بده.

    نمایش جواب
    SELECT * FROM students
WHERE city IN ('Tehran', 'Isfahan') AND grade >= 15;

  3. کدام شهر بالاترین میانگین نمره را دارد؟ فقط همان یک ردیف را نشان بده.

    نمایش جواب
    SELECT city, AVG(grade) AS average FROM students
GROUP BY city ORDER BY average DESC LIMIT 1;

  4. به نمره‌ی همه‌ی دانش‌آموزهای شیراز یک نمره اضافه کن.

    نمایش جواب
    UPDATE students SET grade = grade + 1 WHERE city = 'Shiraz';

  5. عنوان هر درس را با تعداد دانش‌آموزهایش فهرست کن.

    نمایش جواب
    SELECT title, COUNT(*) AS students FROM courses GROUP BY title;

همین را در آزمایشگاه تمرین کن

یادت بماند
  • جدول یعنی ردیف و ستون؛ SQL ردیف‌هایی را که می‌خواهی توصیف می‌کند.
  • SELECT ستون‌ها FROM جدول WHERE شرط ORDER BY ستون LIMIT تعداد;
  • GROUP BY برای هر گروه یک ردیف می‌سازد و JOIN … ON جدول‌ها را از راه id وصل می‌کند.
  • UPDATE یا DELETE بدون WHERE یعنی همه‌ی ردیف‌ها.
  • ورودی کاربر را هیچ‌وقت به SQL نچسبان — از جای‌نگه‌دار استفاده کن.
