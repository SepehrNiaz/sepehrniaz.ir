مبانی جاوااسکریپت برای وب

زبانی که در هر مرورگری اجرا می‌شود — از جمله همین سایت. متغیرها، توابع، و واکنش‌دادن یک صفحه.

بعد از این درس می‌توانی
  • با const و let مقدار تعریف کنی
  • تابع بنویسی و صدایش بزنی
  • کاری کنی یک عنصر صفحه به کلیک واکنش نشان بدهد

جاوااسکریپت تنها زبان برنامه‌نویسی است که به‌صورت بومی در مرورگرها اجرا می‌شود، و همین آن را به زبان وب‌سایت‌های تعاملی تبدیل کرده. هر چیزی که در همین صفحه حرکت می‌کند جاوااسکریپت است. همین الان می‌توانی امتحانش کنی: ابزار توسعه‌دهنده‌ی مرورگر را باز کن (F12) و در Console تایپ کن.

متغیرها و متن

برای مقداری که تغییر می‌کند از let و برای مقدار ثابت از const استفاده کن. متن (یک «رشته») داخل گیومه می‌آید، و بک‌تیک (`) اجازه می‌دهد مقدارها را مستقیم با ${…} داخل متن بگذاری.

توابع

یک تابع، بلوکی نام‌دار از کد است که ورودی می‌گیرد و یک نتیجه برمی‌گرداند. به تو اجازه می‌دهد چیزی را یک بار بنویسی و بارها استفاده کنی.

واکنش‌دادن صفحه

کار اصلی جاوااسکریپت در مرورگر، پاسخ‌دادن به کاربر است. یک عنصر را در صفحه پیدا می‌کنی و به آن می‌گویی وقتی اتفاقی افتاد چه کند — اینجا، وقتی روی یک دکمه کلیک شد.

هر چیزی در این وب‌سایت — ورق‌خوردن کتاب، دستیار گفتگو، تعویض زبان — جاوااسکریپت ساده است، بدون هیچ فریم‌ورکی. سورس صفحه را ببین تا بخوانی‌اش.

جاوااسکریپت کجا اجرا می‌شود

جاوااسکریپت تنها زبان برنامه‌نویسی است که همه‌ی مرورگرها می‌فهمند، پس روی دستگاه خود بازدیدکننده اجرا می‌شود، نه روی سرور. هر صفحه سه لایه دارد: HTML محتواست، CSS ظاهر است و جاوااسکریپت رفتار. اسکریپت را با تگ script به صفحه وصل می‌کنی و پیام‌ها و خطاهایش را در کنسول مرورگر می‌بینی.

انواع مقدار و تله‌های بینشان

  • هر چیزی که در فرم تایپ شود به شکل متن می‌رسد. قبل از حساب‌کردن با Number(value) تبدیلش کن.
  • === مقدار و نوع را مقایسه می‌کند. == اول تبدیل می‌کند و برای همین 5 == "5" درست می‌شود. همیشه === بنویس.
  • undefined یعنی «مقداری داده نشده» و null یعنی «عمداً خالی».
  • رشته‌ی قالبی با بک‌تیک و ${ } نوشته می‌شود: `Hello ${name}` .

تصمیم و حلقه

آرایه: ابزارهایی که هر روز استفاده می‌کنی

شکل کوتاه (p) => p + 1 یک «تابع پیکانی» است: p را می‌گیرد و p + 1 را برمی‌گرداند. همان function (p) { return p + 1; } است. ابزارهای روزمره‌ی دیگر: push به انتها اضافه می‌کند، pop آخری را برمی‌دارد، length می‌شمارد، sort مرتب می‌کند و forEach برای هر عضو کاری انجام می‌دهد.

شیء و JSON

JSON.stringify شیء را به متن و JSON.parse متن را دوباره به شیء تبدیل می‌کند. با همین دو می‌توانی داده را در مرورگر ذخیره کنی: localStorage.setItem("device", JSON.stringify(device)) حتی بعد از بستن صفحه نگهش می‌دارد و JSON.parse(localStorage.getItem("device")) آن را برمی‌گرداند.

تغییر صفحه: DOM

مرورگر وقتی HTML را می‌خواند درختی از شیءها به اسم DOM می‌سازد. جاوااسکریپت می‌تواند هر عنصر این درخت را پیدا کند و تغییر بدهد و صفحه همان لحظه به‌روز می‌شود.

برای هر چیزی که بازدیدکننده تایپ کرده از textContent استفاده کن. innerHTML متن را HTML حساب می‌کند و بازدیدکننده می‌تواند اسکریپت وارد صفحه‌ات کند — حمله‌ای که XSS نام دارد.

رویدادها و فرم‌ها

یک پروژه‌ی کوچک کامل: فهرست دستگاه‌ها

این یک فایل همه‌چیز را کنار هم می‌گذارد: آرایه‌ای از شیءها، تابعی که صفحه را از روی آن آرایه می‌کشد، فرمی که به آن اضافه می‌کند، کلیکی که یک مورد را تغییر می‌دهد و localStorage تا فهرست فردا هم سر جایش باشد. در زبانه‌ی HTML آزمایشگاه تمرین بچسبان و امتحانش کن.

پیداکردن باگ‌های خودت

  • اول کنسول را باز کن (F12). خط قرمز اسم فایل و شماره‌ی خطِ مشکل را می‌گوید.
  • مقداری را که مطمئن نیستی، درست قبل از خطی که خطا می‌دهد console.log کن.
  • «Cannot read properties of null» یعنی querySelector چیزی پیدا نکرده: id و جای تگ script را بررسی کن.
  • «x is not defined» تقریباً همیشه غلط املایی است یا متغیری که بیرون از بلوک خودش استفاده شده.
  • هر بار فقط یک چیز را عوض کن و صفحه را تازه کن.

آرایه، شیء و صفحه

در جاوااسکریپت دو ظرف بیشتر کارها را انجام می‌دهند. آرایه یک فهرست مرتب است: [22, 80, 443]. شیء چند مقدار اسم‌دار را کنار هم می‌گذارد: { name: "router", ip: "192.168.1.1" }. برنامه‌های واقعی بیشتر آرایه‌ای از شیءها هستند و حلقه‌هایی که رویشان حرکت می‌کنند.

  • به‌طور پیش‌فرض const بنویس و فقط وقتی مقدار باید عوض شود let.
  • === دقیق مقایسه می‌کند. از == دوری کن که بی‌صدا نوع را تبدیل می‌کند.
  • در صفحه‌های خودت F12 را بزن تا کنسول باز شود — خطاها آنجا با رنگ قرمز دیده می‌شوند.
  • document.querySelector یک عنصر را پیدا می‌کند و .textContent متنش را عوض می‌کند.
  • اسکریپت باید بعد از ساخته‌شدن عنصر اجرا شود: تگ script را آخر صفحه بگذار.

اشتباه‌های رایج

  • تغییردادن یک const و گرفتن خطای «Assignment to constant variable».
  • querySelector مقدار null می‌دهد چون id غلط نوشته شده یا اسکریپت زود اجرا شده.
  • فراموش‌کردن return — آن‌وقت تابع undefined برمی‌گرداند.

تمرین

اول خودت امتحان کن، بعد جواب را باز کن.

  1. تابعی به اسم square(n) بنویس و square(7) را چاپ کن.

    نمایش جواب
    function square(n) {
  return n * n;
}
console.log(square(7));

  2. تعداد عضوهای const ports = [22, 80, 443]; را چاپ کن.

    نمایش جواب
    console.log(ports.length);

  3. با حلقه‌ی for عددهای ۱ تا ۵ را چاپ کن.

    نمایش جواب
    for (let i = 1; i <= 5; i++) {
  console.log(i);
}

  4. ایراد این کد چیست؟ const count = 0; count = count + 1;

    نمایش جواب
    مقدار const را نمی‌شود عوض کرد. با let تعریفش کن.

همین را در آزمایشگاه تمرین کن

یادت بماند
  • const و let مقدار نگه می‌دارند و تابع به یک کار اسم می‌دهد.
  • آرایه فهرست است و شیء مقدارهای اسم‌دار.
  • صفحه از راه رویدادهایی مثل click واکنش نشان می‌دهد.
