پایتون از صفرِ مطلق

برای کسی که تا حالا برنامه ننوشته: برنامه چیست، پایتون خط‌هایت را چطور می‌خواند و چرا فاصله‌ی اول خط مهم است — قدم‌به‌قدم و دانه‌دانه.

بعد از این درس می‌توانی
  • توضیح بدهی برنامه چیست و پایتون چطور آن را می‌خواند
  • بدون کمک print، متغیر، if / elif / else، for، while و def بنویسی
  • دقیق بگویی چرا و کجا یک خط باید تورفته باشد و خطای IndentationError را رفع کنی

برنامه چیست؟

برنامه فهرستی از دستورالعمل‌هاست که در یک فایل متنی نوشته شده. کامپیوتر فایل را از بالا، خط‌به‌خط می‌خواند و دقیقاً همان کاری را می‌کند که هر خط می‌گوید — نه بیشتر و نه چیزی که به او نگفته‌ای. حدس نمی‌زند منظورت چه بوده. سخت‌گیرانه به نظر می‌رسد و هست، ولی خبر خوبی هم هست: وقتی چیزی خراب می‌شود، دلیلش همیشه روی صفحه جلوی چشمت نوشته شده.

پایتون یکی از زبان‌هایی است که می‌توانی این دستورها را با آن بنویسی. طوری طراحی شده که راحت خوانده شود و برای همین مدرسه‌ها، دانشمندان، مهندس‌های شبکه و تیم‌های امنیت همه از آن استفاده می‌کنند. لازم نیست ریاضی‌ات قوی باشد. صبر لازم داری و عادتِ اینکه مثال‌ها را خودت تایپ کنی.

زبانه‌ی پایتون آزمایشگاه تمرین را در پنجره‌ی دیگری باز کن و هر مثال این درس را تایپ کن. خواندن حدود ده درصد یاد می‌دهد؛ بقیه را تایپ‌کردن یاد می‌دهد.

اولین خط: print

به هر تکه دقت کن، چون همه‌ی خط‌های بعدی از همین تکه‌ها ساخته می‌شوند. print اسم یک دستور است (پایتون به آن «تابع» می‌گوید) که چیزی را روی صفحه نشان می‌دهد. پرانتزها ( ) چیزی را که به دستور می‌دهی نگه می‌دارند و باید باز و بسته شوند. علامت‌های نقل‌قول " " به پایتون می‌گویند «این متن است، دقیقاً همان‌طور که نوشته شده نشانش بده». بدون نقل‌قول پایتون سعی می‌کند حسابش کند — برای همین print(2 + 3) عدد ۵ را نشان می‌دهد ولی print("2 + 3") خودِ نویسه‌های 2 + 3 را. کاما بین دو چیز، هر دو را با یک فاصله بینشان چاپ می‌کند.

  • حروف بزرگ و کوچک مهم‌اند: Print و PRINT وجود ندارند؛ فقط print هست.
  • هر ( یک ) می‌خواهد و هر " یک " دوم.
  • هر خط یک دستور. آخر خط نقطه یا نقطه‌ویرگول نمی‌گذاری.
  • خطی که با # شروع شود «توضیح» است: یادداشتی برای آدم‌ها. پایتون از رویش رد می‌شود.

متغیر: اسم‌گذاشتن روی یک مقدار

متغیر اسمی است که به یک مقدار اشاره می‌کند، مثل برچسب روی یک جعبه. با یک علامت مساوی ساخته می‌شود: اسم سمت چپ و مقدار سمت راست. خط age = 17 را «بگذار age برابر ۱۷ باشد» بخوان، نه «age مساوی ۱۷ است». برای همین خط دوم پایین بی‌معنی نیست: یعنی «مقدار فعلی age را بردار، یکی اضافه کن و نتیجه را زیر همان اسم ذخیره کن».

نوعمثالچیست
int17عدد صحیح
float3.5عدد اعشاری
str"Sara"متن (رشته‌ای از نویسه‌ها)، همیشه داخل نقل‌قول
boolTrueبله یا نه: فقط True یا False، با حرف اول بزرگ
  • اسم می‌تواند حرف، رقم و خط زیر _ داشته باشد، ولی با رقم شروع نمی‌شود و فاصله ندارد.
  • اسمی انتخاب کن که خودش را توضیح بدهد: student_count بهتر از sc یا x است.
  • name و Name دو متغیر جدا هستند.
  • چند کلمه مال خودِ پایتون است و نمی‌شود اسم متغیر باشد: if، for، def، True، class و حدود سی کلمه‌ی دیگر.

متن و عدد دو چیز متفاوت‌اند

"42" داخل نقل‌قول دو نویسه‌ی متن است؛ 42 بدون نقل‌قول عددی است که می‌شود با آن حساب کرد. پایتون هیچ‌وقت این دو را بی‌صدا قاطی نمی‌کند و همین تو را از یک خانواده‌ی کامل از اشتباه‌ها حفظ می‌کند. وقتی لازم است از یکی به دیگری بروی، عمداً تبدیل می‌کنی: int() عدد صحیح می‌سازد، float() عدد اعشاری و str() متن.

پرسیدن سؤال بله یا نه

برنامه وقتی مفید می‌شود که بتواند تصمیم بگیرد. تصمیم با سؤالی شروع می‌شود که جوابش True یا False است. به مساویِ دوتایی دقت کن: یک = مقدار را ذخیره می‌کند و دوتا == می‌پرسد «این دو یکی هستند؟». قاطی‌کردن این دو رایج‌ترین اشتباه تازه‌کارهاست.

if — و چرا خط بعدی باید با فاصله شروع شود

این همان بخشی است که تقریباً همه را اولش گیج می‌کند، پس آرام پیش می‌رویم. دستور if دو بخش دارد. خط اول سؤال را می‌پرسد و با دونقطه تمام می‌شود. دونقطه یعنی «هر چه بعد از من می‌آید مال من است». خط‌های بعدی که به سمت راست هل داده شده‌اند — با چهار فاصله تورفته‌اند — خط‌هایی هستند که فقط وقتی جواب True باشد اجرا می‌شوند. به مجموعه‌ی این خط‌ها «بلوک» می‌گویند.

چرا فاصله؟ پایتون باید راهی داشته باشد که بفهمد بخشِ «فقط اگر درست بود» از کجا شروع و کجا تمام می‌شود. خیلی از زبان‌های دیگر برای این کار از آکولاد { } استفاده می‌کنند و فاصله‌ها را تزئین حساب می‌کنند. طراح پایتون خودِ فاصله‌ها را قانون قرار داد، چون برنامه‌نویس‌های خوب در هر حال کدشان را تورفته می‌نویسند — پس در پایتون، ظاهر کد همان رفتار کد است. این فاصله‌ها سلیقه نیستند؛ دستور زبان‌اند. اگر خطی را چهار فاصله به چپ ببری، کار برنامه را عوض کرده‌ای.

این چیزی است که پایتون وقتی فراموش کنی می‌گوید — اول فاصله‌ها و بعد دونقطه. هر دو پیام را بخوان: شماره‌ی خط و دقیقاً چیزی را که انتظار می‌رفت می‌گویند.

  • قانون در یک جمله: بعد از خطی که با دونقطه تمام می‌شود همیشه یک بلوک تورفته می‌آید.
  • این برای همه‌ی این خط‌ها درست است: if، elif، else، for، while، def، class، try، except و with.
  • برای هر سطح چهار فاصله بگذار. همه‌ی خط‌های یک بلوک باید دقیقاً به یک اندازه تورفته باشند.
  • در یک فایل کلید Tab و فاصله را قاطی نکن. ویرایشگرهای خوب — و آزمایشگاه تمرین — با زدن Tab چهار فاصله تایپ می‌کنند.
  • بلوک با اولین خطی که به چپ برمی‌گردد تمام می‌شود. کلمه‌ای مثل «پایان» وجود ندارد.

else، elif و بلوک داخل بلوک

else شاخه‌ی «وگرنه» است: وقتی جواب سؤال False بود اجرا می‌شود. elif (کوتاه‌شده‌ی else if) وقتی سؤال اول رد شد سؤال دیگری می‌پرسد. یک بلوک می‌تواند if دیگری داخل خودش داشته باشد و آن‌وقت بلوک درونی چهار فاصله‌ی دیگر تورفته می‌شود — در مجموع هشت‌تا. همیشه می‌توانی با نگاه مستقیم به بالای اولین نویسه‌ی یک خط بفهمی آن خط مال کدام if است.

تکرار: for و while

حلقه یک بلوک را چند بار اجرا می‌کند. for عضوهای یک مجموعه را یکی‌یکی برمی‌دارد؛ range(1, 4) عددهای ۱ و ۲ و ۳ را می‌سازد — عدد آخر حساب نمی‌شود. خط حلقه با دونقطه تمام می‌شود، پس خط‌هایی که تکرار می‌شوند تورفته‌اند، دقیقاً مثل if.

تابع: def، و همان قانون فاصله

تابع بلوکی از کد با یک اسم است، تا بتوانی بدون دوباره‌نویسی دوباره از آن استفاده کنی. با def تعریفش می‌کنی. خط اول را تکه‌تکه نگاه کن: def می‌گوید «دارم یک تابع تعریف می‌کنم»، greet اسمی است که خودت انتخاب کرده‌ای، name داخل پرانتز «پارامتر» است — متغیری که هر چه به تابع داده شود می‌گیرد — و دونقطه‌ی آخر، مثل همیشه، خبر از یک بلوک می‌دهد. پس خط‌های تابع چهار فاصله تورفته‌اند. هر چه زیر def تورفته باشد خودِ تابع است و اولین خطی که به لبه‌ی چپ برگردد بیرون از آن است.

return نتیجه را به جایی که تابع را صدا زده برمی‌گرداند تا بتوانی ذخیره یا چاپش کنی. print فقط چیزی را روی صفحه نشان می‌دهد. این دو یکی نیستند و تابعی که حساب می‌کند ولی return را فراموش کرده مقدار ویژه‌ی None را برمی‌گرداند:

خواندن پیام خطا

خطا وضعیت عادی برنامه‌نویسی است، نه نشانه‌ی اینکه در آن بد هستی. حرفه‌ای‌ها هر روز ده‌ها خطا می‌بینند. تفاوت فقط این است که پیام را با آرامش می‌خوانند: کدام خط، چه نوع خطایی، چه چیزی انتظار می‌رفت. پایتون اغلب راه‌حل را هم پیشنهاد می‌دهد، همان‌طور که اینجا داد.

همه را کنار هم بگذاریم

اشتباه‌های رایج

  • جاانداختن دونقطه در آخر if، else، for، while یا def.
  • تورفته‌نکردن خط بعد از دونقطه — یا تورفتگی ۴ فاصله برای بعضی خط‌های یک بلوک و ۳ فاصله برای بقیه.
  • نوشتن = هنگام پرسیدن سؤال. if age = 18 خطاست؛ باید if age == 18 باشد.
  • جاانداختن نقل‌قول، که باعث می‌شود پایتون دنبال متغیری به اسم Sara بگردد.
  • استفاده از print داخل تابع وقتی منظورت return بوده.

تمرین

اول خودت امتحان کن، بعد جواب را باز کن.

  1. این چه چیزی چاپ می‌کند و چرا؟ x = 5 if x > 10: print("big") print("end")

    نمایش جواب
    فقط: end
x > 10 نادرست است، پس خط تورفته رد می‌شود. print("end") تورفته نیست، پس بیرون از if است.

  2. دو اشتباه را پیدا کن: def double(n) return n * 2

    نمایش جواب
    دونقطه بعد از def double(n) جا افتاده و return باید چهار فاصله تورفته باشد:

def double(n):
    return n * 2

  3. برنامه‌ای بنویس که عددهای ۱ تا ۱۰ را چاپ کند و کنار هر کدام even (زوج) یا odd (فرد) بنویسد. (راهنما: n % 2 برای عددهای زوج صفر است.)

    نمایش جواب
    for n in range(1, 11):
    if n % 2 == 0:
        print(n, "even")
    else:
        print(n, "odd")

  4. تابعی به اسم biggest(a, b) بنویس که بزرگ‌ترِ دو عدد را برگرداند و biggest(7, 12) را چاپ کن.

    نمایش جواب
    def biggest(a, b):
    if a > b:
        return a
    else:
        return b

print(biggest(7, 12))

  5. چرا print("10" + 5) خطا می‌دهد و دو راه رفعش چیست؟

    نمایش جواب
    "10" متن است و 5 عدد. یا هر دو را عدد کن — print(int("10") + 5) جواب ۱۵ می‌دهد — یا هر دو را متن — print("10" + str(5)) جواب 105 می‌دهد.

همین را در آزمایشگاه تمرین کن

یادت بماند
  • پایتون از بالا به پایین می‌خواند، هر خط یک دستور.
  • دونقطه‌ی آخر خط وعده‌ی یک بلوک است؛ بلوک همان خط‌هایی است که زیرش چهار فاصله تورفته‌اند.
  • = ذخیره می‌کند و == می‌پرسد. متن داخل نقل‌قول است.
  • def تابع می‌سازد و return جوابش را برمی‌گرداند.
  • خطا را از خط آخر به بالا بخوان.
