پایتون: اولین برنامه‌های واقعی

متغیرها، متن، تصمیم‌ها و حلقه‌ها — هسته‌ی پایتون، با مثال‌های کوچکی که همان‌طور که می‌خوانی می‌توانی اجرا کنی.

بعد از این درس می‌توانی
  • مقدارها را در متغیر نگه داری و چاپ کنی
  • با if، elif و else تصمیم بگیری
  • با حلقه‌ی for روی یک لیست کار تکراری انجام بدهی

پایتون یک زبان اول عالی است: تقریباً مثل انگلیسی خوانده می‌شود و همه‌جا اجرا می‌شود. اگر لینوکس یا مک داری، از قبل نصب است؛ در ترمینال python3 را تایپ کن. همین مقدار برای مفید بودنِ واقعی کافی است.

مقدارها و متغیرها

یک متغیر، نامی برای یک مقدار است. نوعش را اعلام نمی‌کنی — پایتون خودش تشخیص می‌دهد. دستور print() چیزی را روی صفحه نشان می‌دهد.

گرفتن تصمیم

دستورهای if / elif / else بسته به یک شرط، کدهای مختلفی را اجرا می‌کنند. تورفتگی (فاصله‌های ابتدای خط) همان چیزی است که با آن پایتون می‌فهمد کدام خط‌ها به هم مربوط‌اند — تزئینی نیست.

تکرار با حلقه‌ها

یک حلقه‌ی for به‌ازای هر عضو یک فهرست، یک بار تکرار می‌شود. فهرست چند مقدار را به‌ترتیب نگه می‌دارد و داخل کروشه نوشته می‌شود.

آماده‌سازی و اجرای برنامه

پایتون روی لینوکس و مک از قبل نصب است؛ در ویندوز از python.org دانلودش کن و موقع نصب تیک «Add Python to PATH» را بزن. دو راه برای استفاده هست. نوشتن python3 به‌تنهایی یک خط فرمان تعاملی (>>>) باز می‌کند که هر خط همان لحظه اجرا می‌شود — برای آزمایش خوب است. برای کار واقعی خط‌ها را در فایلی با پسوند .py می‌نویسی و فایل را اجرا می‌کنی.

عدد و متن با جزئیات

  • / همیشه جواب اعشاری می‌دهد؛ // بخش اعشار را دور می‌ریزد؛ % باقی‌مانده را می‌دهد؛ ** یعنی «به توان».
  • رشته‌ی f — رشته‌ای که جلویش f آمده — مقدارها را مستقیم داخل متن می‌گذارد: f"{name} is {age}". علامت :, جداکننده‌ی هزارگان اضافه می‌کند.
  • رشته‌ها ابزار آماده دارند: .upper()، .lower()، .strip() (حذف فاصله‌های دو سر)، .replace(a, b)، .split() و .startswith().
  • in می‌پرسد «این داخل آن هست؟» و True یا False جواب می‌دهد.

لیست و دیکشنری

لیست مقدارها را به ترتیب نگه می‌دارد و با شماره‌ی جایگاه (از صفر) به آن‌ها می‌رسی. دیکشنری مقدارها را زیر یک اسم (کلید) نگه می‌دارد، مثل فرمی با خانه‌های برچسب‌دار. این دو با هم تقریباً هر چیزی را توصیف می‌کنند: شبکه فهرستی از دستگاه‌هاست و هر دستگاه یک دیکشنری.

حلقه‌ی while و تابع با مقدار پیش‌فرض

for برای هر عضو یک بار تکرار می‌کند. while تا وقتی شرط درست است تکرار می‌کند، پس چیزی داخل حلقه باید بالاخره شرط را نادرست کند — وگرنه هیچ‌وقت تمام نمی‌شود. تابع می‌تواند به پارامترهایش مقدار پیش‌فرض بدهد که وقتی صدازننده چیزی ندهد استفاده می‌شود.

  • break زودتر از حلقه خارج می‌شود و continue به دور بعد می‌پرد.
  • return یک مقدار را به صدازننده برمی‌گرداند. تابع بدون return مقدار None می‌دهد.
  • متغیری که داخل تابع ساخته می‌شود فقط همان‌جا وجود دارد.
  • اسم تابع را فعلی بگذار که بگوید چه می‌کند: count_failed، is_open، send_report.

وقتی کار خراب می‌شود: خطاها

خطا شکست نیست؛ پایتون دارد دقیق می‌گوید کجا ایستاده. اول خط آخر را بخوان — نوع خطا را می‌گوید. اگر مشکلی قابل انتظار است، مثل فایلی که شاید نباشد، با try و except بگیرش تا برنامه به‌جای ازکارافتادن مؤدبانه جواب بدهد.

خطایعنی چه
SyntaxErrorخط، پایتونِ درست نیست: دونقطه، پرانتز یا نقل‌قول جا افتاده.
IndentationErrorفاصله‌های اول خط اشتباه است.
NameErrorاز اسمی استفاده کرده‌ای که تعریف نشده — معمولاً غلط تایپی.
TypeErrorدو نوع مقدار قاطی شده، مثل متن + عدد.
IndexError / KeyErrorاز لیست جایگاهی یا از دیکشنری کلیدی خواسته‌ای که وجود ندارد.
FileNotFoundErrorمسیر اشتباه است یا در پوشه‌ای غیر از آنچه فکر می‌کنی هستی.

فایل‌ها و ماژول‌های آماده

with open(...) یک فایل را باز می‌کند و با تمام‌شدن بلوک خودش آن را می‌بندد. حالت "r" می‌خواند، "w" فایل را جایگزین می‌کند و "a" به انتهایش اضافه می‌کند. پایتون صدها ماژول آماده هم دارد که با import وارد می‌شوند. ماژول‌های مفید برای شروع: math، random، datetime، os، json، csv و ipaddress.

یک پروژه‌ی کوچک واقعی: چه کسی به سرورم حمله می‌کند؟

دوازده خط برای یک کار مفید کافی است. این برنامه یک لاگ ورود را می‌خواند، خط‌های رمز اشتباه را نگه می‌دارد، آدرسِ آخر هر خط را برمی‌دارد و می‌شمارد هر آدرس چند بار آمده.

چطور پیشرفت را ادامه بدهی

  • هر مثال را خودت تایپ کن؛ یک چیز را عوض کن و قبل از اجرا نتیجه را حدس بزن.
  • هر هفته یک مسئله‌ی کوچک از خودت حل کن: تغییر نام فایل‌ها، خواندن یک CSV، بررسی فهرستی از آدرس‌ها.
  • وقتی گیر کردی، مقداری را که مطمئن نیستی چاپ کن — بیشتر باگ‌ها حدس اشتباه درباره‌ی محتوای یک متغیرند.
  • کد دیگران را بخوان: شش ابزار این سایت کوتاه‌اند و خط‌به‌خط توضیح داده شده‌اند.

انواع مقدار و اولین تابع

هر مقدار یک نوع دارد. متن رشته (str) است و داخل نقل‌قول می‌آید؛ عدد صحیح int است؛ عدد اعشاری float است؛ True و False از نوع bool هستند. پایتون این‌ها را بی‌صدا قاطی نمی‌کند: "5" + 5 خطاست، چون یکی متن و دیگری عدد است. با int("5") یا str(5) تبدیل کن.

  • تورفتگی بخشی از زبان است: خط‌های داخل if، for و def با چهار فاصله شروع می‌شوند.
  • = مقدار را ذخیره می‌کند؛ == دو مقدار را مقایسه می‌کند.
  • len(x) تعداد عضوهای لیست یا حرف‌های یک رشته را می‌شمارد.
  • range(1, 6) عددهای ۱ تا ۵ را می‌دهد — عدد آخر حساب نمی‌شود.
  • خطا را از پایین به بالا بخوان: خط آخر مشکل را می‌گوید و خط بالاترش جای آن را.

قدم بعدی کجاست

با متغیرها، شرط‌ها و حلقه‌ها همین حالا می‌توانی کارهای کوچک را خودکار کنی. بعد، سراغ توابع (def) برای استفاده‌ی دوباره از کد، و دیکشنری‌ها برای ذخیره‌ی داده‌ی نام‌دار برو. بخش ابزارهای سایت برنامه‌های واقعی پایتون دارد که می‌توانی خط‌به‌خط بخوانی‌شان.

اشتباه‌های رایج

  • جاانداختن دونقطه در آخر if، for یا def.
  • قاطی‌کردن Tab و فاصله، یا تورفتگی نامنظم.
  • نوشتن = به‌جای == داخل if.

تمرین

اول خودت امتحان کن، بعد جواب را باز کن.

  1. عددهای ۱ تا ۵ را هر کدام در یک خط چاپ کن.

    نمایش جواب
    for i in range(1, 6):
    print(i)

  2. با داشتن devices = ["router", "switch", "camera"] تعدادشان را چاپ کن.

    نمایش جواب
    print(len(devices))

  3. تابعی به اسم double(n) بنویس که n ضرب در ۲ را برگرداند و double(21) را چاپ کن.

    نمایش جواب
    def double(n):
    return n * 2

print(double(21))

  4. چرا print("Age: " + 23) خطا می‌دهد و چطور درست می‌شود؟

    نمایش جواب
    متن و عدد با + به هم نمی‌چسبند. از print("Age:", 23) یا print("Age: " + str(23)) استفاده کن.

همین را در آزمایشگاه تمرین کن

یادت بماند
  • متغیر مقدار را نگه می‌دارد و هر مقدار یک نوع دارد.
  • if تصمیم می‌گیرد، for تکرار می‌کند و def به یک کار اسم می‌دهد.
  • تورفتگی و دونقطه اختیاری نیستند.
